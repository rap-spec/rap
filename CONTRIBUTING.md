# Contributing

1. Read [SPEC.md](SPEC.md) and run the vectors against your implementation.
2. Open an issue first for anything beyond a typo. Say what fails today and for whom.
3. A pull request that changes behavior includes a vector that shows the change.
4. By contributing you license your contribution under the licenses in [LICENSE.md](LICENSE.md): CC BY 4.0 for specification text, Apache 2.0 for code and vectors, including the patent grant in Apache 2.0.

Keep proposals about the decision interface. Product features of a particular decision service belong in that service's own documentation.
